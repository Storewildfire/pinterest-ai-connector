# Pinterest AI Connector (MCP)

A personal Model Context Protocol (MCP) server designed to securely integrate personal AI assistants with your authorized Pinterest account data.

## Features

- **Personal AI Bridge**: Enables local AI assistants to search and inspect your Pinterest boards and pins using conversational queries.
- **Local-First Architecture**: Runs locally on your workstation; authentication credentials and access tokens are never transmitted to external cloud servers.
- **Official Pinterest OAuth 2.0**: Connects strictly using standard OAuth 2.0 flows with granular scopes (`user_accounts:read`, `boards:read`, `pins:read`).
- **Privacy & Security Focused**: Zero data retention, no external analytics, no telemetry.
