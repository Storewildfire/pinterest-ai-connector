Privacy Policy

Effective Date: October 17, 2026 • Application: Pinterest AI Connector (Personal MCP Server)
Scope of this Application: This software is a personal, open-source AI connector built using the Model Context Protocol (MCP). It is operated exclusively by the individual account owner (Storewildfire) to interact with their own personal Pinterest account data. It is not offered as a commercial service or public multi-tenant software-as-a-service (SaaS).

1. Overview and Architecture

The Pinterest AI Connector is a client-side integration tool that bridges local AI desktop clients (such as Claude Desktop or custom AI agents) with Pinterest's official API. All core interactions are local-first: API requests are initiated from the user's local computing environment directly to Pinterest’s REST endpoints.

2. Data Accessed via the Pinterest API

The connector accesses only the data explicitly authorized by the account owner through standard OAuth 2.0 permission scopes:

  • Account Profile Information: Basic public profile details (e.g., username, profile image URL) accessed via user_accounts:read.
  • Board Information: Titles, descriptions, privacy state, and pin counts of the user's personal boards accessed via boards:read.
  • Pin Data: Pin descriptions, image URLs, original URLs, and board associations accessed via pins:read.

The connector never accesses or requests sensitive personal identifiers, billing information, payment methods, or direct private messages.

3. Authentication and Token Security

Authentication adheres strictly to the official Pinterest Developer guidelines:

  • OAuth 2.0 Authorization: Access is established using standard OAuth 2.0 authorization code flows with PKCE. The user explicitly grants access on Pinterest’s official consent page.
  • Local Storage of Tokens: Access and refresh tokens are stored locally on the user's personal machine (e.g., in a local configuration file or OS environment variable). Tokens are never sent, synced, or backed up to any central database or third-party web server.
  • Client Secret Protection: Client credentials and access tokens are strictly excluded from version control systems and are protected using local environment boundaries.

4. Third-Party AI Processing

When the account owner prompts their AI assistant to analyze, summarize, or organize their Pinterest content:

  • The specific text metadata of the requested boards or pins (e.g., pin title, description) is transferred into the active context window of the user’s designated AI client (e.g., Anthropic, OpenAI, or local models).
  • Data handling by the AI provider is governed by the respective provider’s terms of service and privacy policies.
  • OAuth credentials, client secrets, and access tokens are strictly sequestered from the prompt context and are never provided to language models.

5. Data Retention, Caching, and Telemetry

  • No Cloud Storage: We do not operate a remote database, user analytics service, or telemetry server. No Pinterest data is mirrored or stored on external servers.
  • Transient In-Memory Caching: API responses are processed in-memory during active sessions to respond to prompts and are discarded upon program termination.

6. User Control and Data Deletion

The account owner retains complete control over their Pinterest connection and data:

  • Revoking Access: You can instantly revoke this application's API permissions at any time via your Pinterest account settings under Pinterest Apps Settings.
  • Deleting Local Data: Deleting the local configuration directory or environment variables immediately purges all stored access tokens from the workstation.
