Pinterest AI Connector

A private, open-source Model Context Protocol (MCP) connector designed to securely bridge personal AI environments with authorized Pinterest data.

Privacy Policy → GitHub Repository →

Overview

This tool serves as an integration layer between AI assistants (such as Claude Desktop or custom AI agents) and Pinterest. It uses Pinterest’s official OAuth 2.0 API to allow the account owner to inspect, query, and search their own boards and saved pins through conversational prompts.

Core Principles & Security Design

🔒 Local-First Control

The connector is executed locally on the user's workstation. Application credentials, access tokens, and API requests remain on local storage and are never proxied through external intermediate servers.

👁 Authorized Scope Only

The application operates strictly under explicit user authorization via OAuth 2.0. It requests only read permissions (such as pins:read and boards:read) necessary to fulfill user requests.

💾 Zero Data Retention

Pinterest data fetched during a query is used exclusively within the active runtime context to answer the user's prompt. No boards, pins, or personal metadata are retained, mirrored, or persisted remotely.

Technical Specifications

  • Protocol: Model Context Protocol (MCP) via JSON-RPC / Standard I/O.
  • Authentication: Pinterest REST API v5 OAuth 2.0 with PKCE authorization.
  • Deployment: Local standalone runner for personal desktop AI interfaces.
  • Open Source: Code publicly inspectable under the MIT license on GitHub.
